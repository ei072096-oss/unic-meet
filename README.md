# unic MEET 恋愛タイプ診断（2026-10-30）

「あなたの恋愛・婚活は何タイプ？」を入口に、タイプを知る → 自分に合う婚活を考える → Zoom無料診断で婚活のプロと今後の婚活方法を考える、という流れです。

## 2026-10-30 見た目の更新
題名を「あなたの恋愛・婚活は何タイプ？」へ統一。Zoom案内は結果の動物画像・無料バッジ・大きなCTA付きのカードに変更。下部のunic MEET紹介は、押せるロゴと大きなサービスボタンを設置。320〜1440pxで横はみ出しと44px以上のタッチ領域を確認。

## 現在の導線
- 主ボタンは「『私の婚活、何から始める？』を見つける」。Zoom無料診断と併記。LINEへ「無料診断希望」の一言で受付でき、動物タイプは任意。
- 婚活の進め方のヒントを探す10問の無料タイプ診断。8問で動物、残り2問で次の一歩の参考を表示。
- 結果に27,000円のコーチング料金、エステ・結婚相談所への直接申し込みは出しません。コーチング・結婚相談所などの詳細は、サービス紹介リンク先で確認する導線です。
- 無料Zoom診断を主導線として掲載。1,980円・4,980円・27,000円や、戦略ミーティングなどの名称は診断画面に掲載しません。
- Zoom無料診断はBOOKING_URLを優先し、空欄の場合は既存公式LINEのLINE_OA_URLから日程調整。登録済みの方の再登録は不要。LINEでは「無料診断希望」の一言で受付。動物タイプは「もしよければ」と任意で案内し、結果が手元になくても受け付けます。入力データの自動引き継ぎはしません。
- 追加の事前アンケートは作らず、必要な確認は日程調整の際に行う運用です。
- 診断結果の閲覧はLINE登録不要。生年月日・出生時刻・回答はブラウザ内のみで処理し、自動転送・保存しません。
- 友達に結果をLINEで送る機能を維持。URLはタイプ／サブタイプのみ。Instagramでシェアも復元し、1080×1920px画像を作成・保存、対応端末ではOS共有できます。Instagramへ自動投稿はしません。紹介とサービスサイトへのボタンを下部に掲載。
- 12タイプの元のキャラに近い個別画像と、実装済み四柱推命を維持。

## 必須設定
site-config.js のBOOKING_URLにZoom無料診断のHTTPS予約URLを設定してください。LINE受付の場合はLINE_OA_URLへ既存公式LINEの友だち追加URLを設定。予約URLを優先します。両方未設定の場合は受付ボタンが準備中です。現在はユーザー指定の既存公式LINE https://lin.ee/wYDO7PH を設定済みです。COACH_CREDENTIALは将来用で、現在の画面には表示しません。

## 起動・検証
既存の/workspace/unic-meetを使用。隔離済みのため明示依頼なしにworktreeは作成しません。静的サイトでビルド・依存導入は不要です。

```
python -m http.server 8767 --bind 127.0.0.1
node tests/logic.cjs
node tests/calendar.cjs
node tests/browser.cjs
node tests/calendar-browser.cjs
node tests/assets.cjs
node tests/share.cjs
```
ブラウザテストは起動済みサーバー、環境付属Playwright・/usr/bin/chromiumを使用します。実機iPhone/AndroidやLINEアプリ操作を保証するものではありません。
